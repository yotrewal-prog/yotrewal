Набор тестов для приложения mathtool.py
=========================================

Тесты 1-8: команда "solve -a A -b B -c C", коэффициенты заданы параметрами.
Таблица результатов:

№  A       B    C    Ожидаемый результат
-- ------- ---- ---- ------------------------------------------------------
1  1       -3   2    Уравнение квадратное; D = 1; x1 = 2.000; x2 = 1.000
2  1       -2   1    Уравнение квадратное; D = 0; x = 1.000
3  1       0    5    Уравнение квадратное; D = -20; Действительных корней нет
4  0       2    -4   Уравнение линейное; x = 2.000
5  0       0    0    ОШИБКА: это не уравнение, неизвестное отсутствует; код 1
6  0       0    7    ОШИБКА: это не уравнение, неизвестное отсутствует; код 1
7  abc     1    1    ОШИБКА: коэффициент не является целым числом; код 1
8  50000   1    1    ОШИБКА: значение вне допустимого диапазона; код 1
